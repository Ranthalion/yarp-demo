## Why should I care?
YARP can can solve a bunch of different problems
- API Gateway: BFF passthrough with API Key/other auth
- Load Balancing
- Migrating a legacy API
- Proxying front ned code to back ends
- Rate Limiting
- Scaling a monolithich API based on the type of activity
- Subscription based routing between free tier and faster performance tiers
- Other arbitrary transformations
- Custom middlewares and extensiblity since it's just more C#.
